- In computing interest rate sensitivity for measurement, Regions compares a set of alternative interest rate scenarios to the results of a base case scenario derived using “market forward rates.” The standard set of interest rate scenarios includes the traditional instantaneous parallel rate shifts of plus 100 and 200 basis points.
